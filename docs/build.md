\# Сборка проекта



\## Настройки сборки



Активная платформа сборки: Windows.



Архитектура: Intel 64-bit.



Build and Run: Local Machine.



В Scene List добавлены сцены:

\- PlatformerDemo

\- TopDownDemo



В окне Build Profiles также отображаются другие целевые платформы, включая Web, macOS, Linux, Android, iOS и другие.



\## Установленные пакеты



В Package Manager обнаружены следующие Unity-пакеты:

\- Custom NUnit

\- JetBrains Rider Editor

\- Test Framework

\- Visual Studio Editor



Также в проект импортирован ассет Simple 2D Template версии 1.2 из Unity Asset Store.



\## Структура проекта



Основные папки Unity-проекта:

\- Assets

\- Packages

\- ProjectSettings



В Assets находится папка IndieMarc, содержащая варианты демонстрационного проекта.



Для выбранного командой варианта PlatformerDemo структура включает:

\- Editor

\- Materials

\- Prefabs

\- Scripts

\- Sprites

\- Tilemap



\## Ассеты PlatformerDemo



\### Materials



В папке Materials присутствует материал:

\### Prefabs



В папке Prefabs присутствуют:

\### Scripts



В папке Scripts присутствуют:

Спрайты разделены на категории:

Поиск по типу AudioClip в Assets не обнаружил отдельных аудиоклипов.
