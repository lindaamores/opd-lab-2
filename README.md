Лабораторная работа №2
Проект по работе с Unity и Git.
Для лабораторной мы использовали готовый шаблон Simple 2D Template и работали с уровнем 2D Platformer.

Что делали
1) работали с проектом через Git и GitHub;
2) разбирались со структурой Unity-проекта;
3) изменяли уровень;
4) работали с ветками и merge-конфликтами;
5) настроили GitHub Actions;
6 ) добавили тесты PlayMode и EditMode;

Документация
Основная документация по проекту находится в папке `docs`.

CI/CD
Для проекта настроен GitHub Actions.

Workflow автоматически запускает:
1) PlayMode Tests;
2) EditMode Tests;
3) сборку под Windows 64-bit.

Тесты и сборка успешно проходят.
